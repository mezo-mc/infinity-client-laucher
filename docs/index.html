Infinity Client Launcher

A Windows launcher for Minecraft: Java Edition 1.21.11 with Fabric. Keep separate mod profiles, add mods from Modrinth, and sign in with your own Microsoft account.

This project is in development and not yet released to the public. This page explains what it does and how it handles your sign-in.

What it does

Everything a player needs to get from sign-in to a running game.

Installs and runs Minecraft
Downloads Minecraft 1.21.11 and the Fabric loader straight from Mojang's and Fabric's servers, finds or downloads Java 21, and starts the game. Closing the launcher doesn't close the game.
Separate mod profiles
Each profile has its own mods folder, color and memory limit. Rename, duplicate or delete them, and switch any mod on or off without deleting it.
Modrinth mod browser
Search Modrinth for Fabric mods built for 1.21.11 and install them in one click. Mods that a mod needs are installed with it, and every file is checked against the hash Modrinth publishes before it is saved.
No admin rights needed
Everything lives in %LOCALAPPDATA%\InfinityClientLauncher. The launcher doesn't write to Program Files or the registry.

How sign-in works

The launcher uses Microsoft's device code flow, so the sign-in page is always Microsoft's own.

  1. The launcher asks Microsoft for a one-time codeIt shows the code and opens Microsoft's own sign-in page, either in a separate window or in your browser.
  2. You sign in on Microsoft's pageYou type your password and approve the sign-in with Microsoft, not with the launcher. The launcher never sees your password.
  3. Microsoft tells the launcher you're signed inThe launcher then exchanges the result with Xbox Live and the Minecraft Services API to check that your account owns Minecraft and to get your player profile.
  4. Your sign-in is kept on your computer onlyThe refresh token that keeps you signed in is stored in the Windows Credential Manager, not in a file.

What the launcher never does

  • Show its own login form or capture your Microsoft password
  • Contain a client secret or any other secret baked into the program
  • Send your Microsoft credentials or tokens to an Infinity server
